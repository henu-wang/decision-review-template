# Contributing to Decision Review Template

Help us improve decision review tools for everyone!

## How to Contribute
1. Fork the repository
2. Create a feature branch
3. Submit a Pull Request

## Ideas
- Templates for specific domains (medical, legal, engineering)
- Automated review scheduling tools
- Dashboard for tracking review metrics
- Integration with project management platforms

## Resources

This project is built on the review and reflection practices curated at [KeepRule](https://keeprule.com), a platform for decision-making wisdom from master thinkers and investors.
